📌 Project Overview
────────────────────────────────────────────────────────────────
Solar System Explorer is an interactive 3D visualization of
our solar system built using Three.js.

The project simulates realistic planetary motion, orbital
mechanics, moons, asteroid belts, and immersive space
environments directly inside the browser.

Users can freely explore the universe by rotating the camera,
zooming into planets, changing simulation speed, and viewing
detailed scientific information about each celestial body.


🚀 Features
────────────────────────────────────────────────────────────────

🌍 Interactive 3D Solar System
    • Realistic Sun and planets
    • Elliptical planetary orbits
    • Real-time orbital animation
    • Relative orbital speed simulation

🪐 Planetary Information Panel
    Click on any planet to explore:
        ➤ Distance from Sun
        ➤ Orbital Period
        ➤ Orbital Velocity
        ➤ Diameter
        ➤ Mass
        ➤ Surface Gravity
        ➤ Rotation Period
        ➤ Temperature
        ➤ Atmospheric Composition
        ➤ Number of Moons

🌠 Immersive Space Environment
    • 14,000+ procedural stars
    • Asteroid belt simulation
    • Saturn ring system
    • Planet glow & atmosphere effects

🌙 Moon Simulation
    Includes major moons such as:
        ➤ Earth's Moon
        ➤ Phobos (Mars)
        ➤ Titan (Saturn)
        ➤ Io
        ➤ Europa
        ➤ Ganymede
        ➤ Callisto

🎮 User Controls
────────────────────────────────────────────────────────────────

    Drag Mouse        → Rotate Camera
    Scroll Wheel      → Zoom In / Out
    Click Planet      → View Information
    Speed Slider      → Adjust Simulation Speed
    Pause Button      → Pause Simulation
    Reset Button      → Reset Camera View
